# BeaconPlus Addons

Public issue tracker and addon distribution catalog for BeaconPlus.

This repository contains only open-source integration addons. It does **not**
contain or distribute the BeaconPlus plugin JAR.

- Use the issue forms for BeaconPlus bugs, compatibility reports, and features.
- Addons are published as GitHub Release assets and indexed by `catalog.json`.
- BeaconPlus verifies addon SHA-256 checksums before staging updates.

See [CONTRIBUTING.md](CONTRIBUTING.md). Addon source is Apache-2.0 licensed;
the commercial BeaconPlus plugin is separate and is not covered by that license.
